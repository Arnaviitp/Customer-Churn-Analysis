# Customer Churn Analysis 🚀

Predict customer churn and identify key factors driving churn, using data exploration, feature engineering, modeling, and interactive visualization.

---

## 🎯 Objective

- Identify customers who are likely to churn (cancel their service)  
- Analyze churn drivers such as demographics, usage patterns, and service plans  
- Build accurate, interpretable models and provide actionable business insights

---

## 📌 Project Highlights

- Data cleaning & preprocessing  
- Exploratory Data Analysis (EDA) with charts & correlation analysis  
- Feature engineering: encoding, scaling, derived features  
- Model training & selection: Logistic Regression, Random Forest, XGBoost  
- Model evaluation using metrics like accuracy, precision, recall, ROC‑AUC  
- Feature importance and SHAP values for explainability  
- Optional: Interactive dashboard or web app for decision support
